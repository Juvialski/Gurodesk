PURPOSE
1. Fix overlapping school search rows on mobile.
2. Remove the first-20 / letter-B browsing cutoff by adding paginated results.
3. Add District as first-class teacher/school identity.
4. Persist District in profiles and immutable historical school snapshots.
5. Put District into built-in Lesson Plan, TOS, and Assessment document headers.
6. Expose District to lesson DOCX custom-template mappings and TOS XLSX mappings.
7. Support verified official School ID -> District mappings where available.
8. NEVER infer district from municipality, province, or school name.

IMPORTANT SOURCE RULE
DepEd NID is the official national source for Region -> Division -> School ID/School Name,
but it does not expose a complete nationwide district mapping.

District mappings may be added only when an official DepEd source explicitly maps a School ID
to a District (for example an official Schools Division school directory).
Until then the teacher may enter District once; save it as:
  district_source = 'manual'
  district_verified = false

Do not label a teacher-entered district as verified.

PRODUCTION DATABASE
The equivalent district schema/RPC migration has already been applied directly to the connected
GuroDesk Supabase project. KEEP the migration file in the repository anyway so fresh/upgrade
environments and migration history remain reproducible. It is idempotent.
