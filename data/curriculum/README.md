# Verified curriculum manifests

This directory is for **competency-level source-reviewed curriculum manifests**, not the broader offering catalog.

A manifest may become executable only after its exact competency text and provenance are reviewed from an authoritative source. The official national offering catalog lives in `src/data/curriculumCatalog.ts`; private-school curricula are teacher-owned database records created through the review/approval workflow.

Do not generate official DepEd competency text from model memory.
