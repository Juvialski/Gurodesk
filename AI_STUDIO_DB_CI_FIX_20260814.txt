PURPOSE
-------
This root-relative overlay repairs two confirmed database release blockers:

1. Supabase production has 15 migration versions after 202608130039 that are
   recorded remotely but missing from the GitHub migration directory.
   Supabase therefore reports:
   "Remote migration versions not found in local migrations directory."

2. GitHub upgrade CI fails when migration
   202608140041_assessment_provenance_and_rubric_scoring.sql calls the
   multi-mode assessment save RPC, because that RPC inserts version metadata
   into public.document_versions columns that the Phase 1 schema never added:
   title, status, created_by.

----------------

This adds nullable:
- public.document_versions.title
- public.document_versions.status

It intentionally does NOT backfill old version rows, because using the current
document title/status for an old version would falsify historical metadata.
