# Source and affiliation notice

GuroDesk is an independent teacher-productivity project and is **not an official Department of Education (DepEd) system** and does not imply DepEd endorsement.

Where the project includes structured facts transcribed from DepEd curriculum guides, orders, memoranda, or other official materials, the source metadata is preserved so teachers can trace the record back to DepEd. GuroDesk-generated IDs, sequence fields, database schemas, validation metadata, and software behavior are project metadata and should not be mistaken for official DepEd codes unless the source explicitly supplies such a code.

The application must not use the DepEd seal, logo, or official insignia without authorization. Built-in exports use independent layouts unless a separately verified school/division template is added. Student tests, teacher copies, and answer keys do not place GuroDesk branding in the submitted document. Draft exports are visibly labelled where applicable, and the application must not present a generated layout as an official DepEd-issued form.

## Phase 5 learner-data notice

Phase 5 introduces teacher-entered learner and assessment-result records. These are personal data and are minimized to what a teacher needs to identify a learner inside an owned assignment/section: an internal identifier, display name, optional teacher-local reference, active state, and the result evidence required for the teacher's assessment workflow. GuroDesk does not require an LRN, birth date, address, contact details, guardian details, health/disability data, socioeconomic data, or passwords for this phase.

Learner, response, score, remediation, export-template, and result-session records must remain strictly scoped to the authenticated owning teacher. They are not public records, are not shared between teachers, and must not be sent to Gemini. Optional remediation assistance receives only de-identified aggregate competency context and teacher-selected constraints; deterministic application code remains authoritative for scoring and analysis. Teachers and schools remain responsible for lawful notice, access, retention, archival, and deletion decisions under their approved privacy and records policies. This project does not invent a statutory retention period or represent its analysis thresholds as a DepEd mandate.

Phase 5 submitted reports are intentionally unbranded and omit AI prompts, model metadata, internal audit data, and technical identifiers. A learner name may appear only in a teacher-authorized results report or worksheet where it is needed for that report's purpose.
